# 训练曲线说明

此目录保留项目已有的曲线图片，涵盖奖励、KL、loss、通过率、交互步数等主题。

当前仓库尚未附带能逐一对应这些图片的原始指标日志、运行配置、模型 checkpoint、绘图脚本和实验清单。图片因此仅作为已有材料保留，不单独用于证明性能提升、消融结论或基准排名。

可复核的实验报告应将每张图与以下材料对应：

- Git commit 与完整配置快照。
- 基础模型、数据版本、预处理方式和测试数量。
- 硬件、随机种子、采样设置与交互 / token 预算。
- metrics-*.jsonl、train_metrics.jsonl 等原始日志。
- checkpoint 标识、绘图命令，以及对照实验的相同设置与变化项。

指标定义和运行步骤见 [项目首页](../../README.md) 与 [运行指南](../VICO%20怎么跑项目.md)。
